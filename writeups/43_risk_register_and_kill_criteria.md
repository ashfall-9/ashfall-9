# 43 — Risk Register and Pivot Criteria

## Purpose

This project is ambitious enough that some assumptions will fail. A good specification should say how to notice failure early and how to pivot without corrupting the architecture.

## Risk table

| Risk | Trigger | Mitigation | Pivot criterion |
|---|---|---|---|
| Vulkano lacks needed feature coverage | Renderer needs feature not exposed or too awkward in wrapper. | Use `gfx_vk` raw/ash backend module with strict ownership rules. | If more than 30% of backend code becomes raw, re-evaluate wrapper role. |
| winit lifecycle bugs | Resize/minimize/suspend causes swapchain or surface failures. | Keep winit isolated in `app_desktop`; add lifecycle smoke tests. | If a target platform is unstable, narrow platform support for milestone. |
| Burn is not useful for local eval/model tasks | Backend support/performance/tooling does not match needs. | Keep `LocalModelRunner` trait; use alternative model backend. | If spike fails, do not force Burn into runtime. |
| AI visual judging is noisy | Calibration examples score inconsistently or regressions are missed. | Use calibration set, human review, multi-signal metrics. | If evaluator fails calibration twice, freeze promotion and replace/recalibrate evaluator. |
| Clouds miss performance budget | Cloud pass exceeds budget across profiles. | Add lower-res raymarch, temporal reprojection, quality tiers, profile-specific knobs. | If high profile cannot reach budget after two optimization passes, lower target quality or defer feature. |
| Clouds look good only in one camera path | Locked eval scenes reveal tiling/flicker/artifacts. | Add varied seeds and temporal sequences. | If repeated motifs remain, revisit density/noise model before adding new features. |
| Render graph becomes over-engineered | Basic sky rendering blocked by graph abstraction work. | Keep first graph minimal; defer aliasing/async compute. | If graph work blocks visual progress for two weeks, implement minimal fixed graph and resume. |
| Shader ABI bugs consume time | Visual failures trace to layout mismatch or descriptor errors. | Add ABI tests, reflection, stable wire types. | If ABI churn is high, freeze shader ABI for milestone and only add fields through extension buffers. |
| Evaluation infrastructure becomes the project | Dashboard/reporting work delays renderer. | Minimal artifact schema first; dashboard later. | If dev_web blocks renderer, remove from milestone branch. |
| Scope creep | New object classes appear before sky certification. | AGENTS.md and release gate forbid it. | Revert scope-creep changes unless explicitly approved as separate research branch. |
| Voice/persona legal risk | Real-person voices or likenesses enter dataset without consent. | Governance metadata and no-impersonation policy. | Block merge and quarantine assets. |
| Reference dataset rights risk | Images lack source/license metadata. | Reference manifest required. | Invalid references cannot be used for certification. |

## Dependency spike exit states

Every dependency spike must end in one of these states:

```text
Accepted:
  dependency meets purpose, boundary is clear, tests pass

Accepted with restrictions:
  usable only in specific crates/features or non-hot paths

Deferred:
  promising but not needed for current milestone

Rejected:
  does not meet needs; fallback chosen
```

Do not leave a spike in “maybe” state.

## Renderer pivot rules

### When to use raw Vulkan/ash

Use raw Vulkan only when:

```text
- Vulkano does not expose a required feature
- wrapper path causes measured unacceptable overhead
- interop requires raw handles in backend internals
- a minimal raw spike proves the path
```

Do not use raw Vulkan just because an example exists online.

### When to defer Vulkan 1.4 path

Defer Vulkan 1.4-specific implementation if:

```text
- target hardware lacks support
- driver support is unstable
- Vulkano/raw setup would delay milestone-1 sky rendering
- Vulkan 1.3 fallback is sufficient
```

### When to avoid async compute

Avoid async compute until:

```text
- the graphics queue is saturated
- a pass has independent work
- profiler capture shows overlap opportunity
- synchronization/ownership transfers are generated by the graph
```

## Eval pivot rules

Replace or recalibrate an evaluator when:

```text
- calibration set fails
- known-bad images receive passing scores
- known-good images receive failing scores without explanation
- score distribution changes after provider/model update
- output JSON schema failure rate is unacceptable
```

Certification must pause until evaluator configuration is valid again.

## Scope-control kill criteria

A feature should be removed from the current milestone branch when it violates any of these:

```text
- not sun/atmosphere/cloud related
- requires new asset class unrelated to sky
- blocks capture/eval/profiling infrastructure
- introduces provider dependency into renderer
- weakens performance gates
- changes certification thresholds to pass itself
```

Removal does not mean the feature is bad. It means it belongs to a later milestone.
